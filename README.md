# 쾌락실

슬랙 채널에서 친구들이랑 노는 미니게임 봇이에요.

| 게임 | 규칙 |
| --- | --- |
| 💣 폭탄 돌리기 | 최근 1시간 안에 채팅한 사람 중 한 명에게 폭탄이 떨어져요. 다른 사람을 @멘션하면 넘어가고, 1~5분 사이에 터져요. 터진 사람은 랭킹의 폭사왕에 기록돼요 💀 |
| 👾 야생 출몰 | 자동을 켜면 이모지 몬스터가 나타나요. 리액션을 제일 먼저 누른 사람이 포획하고, 1분 안에 아무도 못 잡으면 도망가요. 흔함 18 · 희귀 10 · 전설 3, 총 31종 |
| 🔤 초성 퀴즈 | 점심 메뉴 초성 문제가 나와요. 3분 안에 채팅으로 정답을 치면 1점이고, 이번 주 1등은 퀴즈왕 👑 |
| 🎲 자동 모드 | 게임마다 따로 켜고 꺼요. 켜 둔 게임은 한 판 끝나면 20초 뒤에 다음 판이 시작돼요 |
| 📈 이모지 거래소 | 봇의 앱 홈 탭에서 해요. 최근 24시간 동안 많이 쓰인 이모지일수록 비싸지는 가짜 주식시장이에요 |

## 놀기

채널에서 `/game`을 치면 그 채널이 게임 채널이 되고 메뉴가 올라와요. 자동 모드는 꺼진 채로 시작하니까, 원하는 게임만 켜 주세요.

- **💣 지금 던지기** · **🔤 지금 내기** — 바로 한 판 시작
- **도감** · **랭킹** — 누른 사람에게만 보여요
- **자동 켜짐 / 꺼짐** — 게임마다 옆에 붙어 있어요. 누를 때마다 바뀌고, 켜지면 초록색이에요

퀴즈는 자동 모드와 상관없이 매일 12시에 한 번 나와요.

## 설치

### 준비물

**Node 24 이상**만 있으면 맥, 윈도우, 리눅스 어디서든 돌아가요 (Node에 들어 있는 SQLite를 써서 따로 DB를 설치할 필요가 없어요). 소켓 모드로 슬랙과 연결해서 공개 주소나 포트 열기도 필요 없어요.

| 운영체제 | Node · pnpm 설치 |
| --- | --- |
| 맥 | `brew install node pnpm` |
| 윈도우 | `winget install OpenJS.NodeJS pnpm.pnpm` |
| 리눅스 | [nodejs.org](https://nodejs.org) 안내대로 Node 24 설치 후 `npm install -g pnpm` |

설치 후 `node -v`가 `v24` 이상인지 확인해 주세요. pnpm 대신 npm을 써도 돼요 (`npm install` · `npm start`).

### 봇 켜기

1. 코드 받기

   ```bash
   git clone https://github.com/E-JIWON/slack-thrill-bot.git
   cd slack-thrill-bot
   pnpm install
   ```

2. [api.slack.com/apps](https://api.slack.com/apps)에서 **Create New App → From a manifest**를 고르고 `manifest.yml` 내용을 붙여 넣어요
3. **Basic Information → App-Level Tokens**에서 `connections:write` 권한으로 앱 토큰(`xapp-`)을 만들어요
4. **Install App**으로 워크스페이스에 설치하고 봇 토큰(`xoxb-`)을 복사해요
5. `.env.example`을 `.env`로 복사하고 두 토큰을 넣은 뒤 켜요

   ```bash
   pnpm start
   ```

6. 놀 채널에서 `/invite @thrill`로 봇을 부르고 `/game`을 쳐요

## 워크스페이스 여러 개

워크스페이스마다 슬랙 앱을 하나씩 만들고, `.env` 파일도 따로 만들어요. 기록이 섞이지 않게 `DB=`로 저장 파일 이름을 다르게 정해 주세요.

```bash
node --env-file=.env.second index.js
```

## 알아 둘 것

- 봇은 **켜 둔 컴퓨터에서만** 돌아가요. 컴퓨터를 끄거나 잠자기에 들어가면 봇도 멈춰요. 계속 켜 두는 컴퓨터(맥 미니 등)나 서버에서 돌리는 게 좋아요
- 요청이 올 때만 깨어나는 서버리스(버셀, 파이어베이스 함수 등)에서는 타이머와 상시 연결이 끊겨서 안 돌아가요

- 도감, 점수, 폭사 기록은 저장 파일(`*.db`)에 남지만, 진행 중이던 폭탄·퀴즈·몬스터는 봇을 끄면 사라져요
- 봇이 채널에 초대돼 있어야 글을 올리고 채팅을 볼 수 있어요
- 12시 퀴즈는 봇을 켠 컴퓨터의 시간 기준이에요
